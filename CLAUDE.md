# Переход на Codex

[AGENTS.md](AGENTS.md) определяет действующий процесс разработки и выпуска. Основной оркестратор — Codex. Для постановки задачи используй [руководство Codex](docs/codex-orchestration.md).

В этой сессии Claude не запускай архивную команду `/task` и агентов из `.claude/`, не выполняй merge, deploy и rollback по их инструкциям. Первоначальные материалы сохранены в [архиве переходного периода](docs/legacy/claude/README.md).
